# The Wild Oasis

A hotel management application that allows hotel employees to manage cabins, bookings, and guests efficiently.

## Features

- Dashboard with hotel statistics and charts.
- Manage cabins (Create, Update, Delete).
- Manage bookings and guests.
- Check-in and check-out functionality.
- Manage hotel settings.
- User authentication.
- Dark mode.
- Responsive user interface.
- Form handling and validation.

## Tech Stack

- React
- React Router
- React Query
- React Context API
- React Hook Form
- Supabase (Authentication & Database)
- Styled Components
- Recharts
